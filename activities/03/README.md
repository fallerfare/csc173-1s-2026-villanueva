# Dataset Setup Instructions

## Setup Instructions

1. Obtain the `my_dataset` folder from the provided course materials or the original dataset source.
2. Compress the entire `my_dataset` folder into a ZIP archive named:

   ```text
   my_dataset.zip
   ```

3. Place the ZIP file in the following directory:

   ```text
   activities/03/
   ```

   The resulting directory structure should be:

   ```text
   activities/
   └── 03/
       ├── my_dataset.zip
       ├── README.md
       └── ...
   ```

4. Run the notebook. It will use `my_dataset.zip` as its dataset source.

## Notes

- Ensure the archive is named **exactly** `my_dataset.zip`, as the notebook expects this filename.
- If the notebook cannot locate the dataset, verify that the ZIP file is in the correct directory and has not been renamed.
